    提醒事项同步 CalDAV

    在 iPhone / Mac 的「提醒事项」里添加一个 CalDAV 账户，就会多出一个「EasyLife」列表，双向同步：手机上新建、打勾、修改、删除，这里都会跟着变，反之亦然。

    1. iPhone 打开「设置 →（App →）提醒事项 → 账户 → 添加账户 → 其他 → 添加 CalDAV 账户」（Mac：系统设置 → 互联网账户 → 添加其他账户 → CalDAV 账户，类型选「手动」）。
    2. 服务器填上面的地址，用户名填你的邮箱，密码填生成的同步密码（不是登录密码）。
    3. 保存后打开「提醒事项」，就能看到「EasyLife」列表。

    重新生成或停用后，旧密码立即失效，已添加的设备需要更新密码。只同步一个列表；归档的任务不会出现在手机上。
